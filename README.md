# Ynamdar Market Clone 🛒 (English)

This project is a modern frontend clone of **Ynamdar**, one of the most popular online shopping platforms in Turkmenistan. The design and functionality have been carefully crafted to closely match the original website.

---

## ❓ What Problems Does This Project Solve? (Problem Solving)

* **Fast and Lightweight:** Optimized for lightweight performance so that pages load quickly even in areas with slower internet speeds.
* **Fully Responsive:** The layout automatically adapts to any screen size, providing a seamless experience on mobile devices, tablets, and desktops.
* **Ready-to-Use Components:** Essential e-commerce features like the shopping cart and dynamic item counters work stably and reliably.

---

## 🛠️ What Features Does It Provide?

* **Dynamic Product Search:** Users can quickly find products using the interactive search bar.
* **Language Switcher:** Supports multiple languages (such as Turkmen and Russian) so users can easily switch to their preferred language.
* **Categories and Brands:** Products are organized by categories and brands for easy navigation.
* **Cart & Quantity Adjuster:** Users can add products to their cart and dynamically increase or decrease the quantity of items.

---

## 👥 Who Is This Project Useful For?

* **E-commerce Learners:** Frontend developers who want to study the structure and design of real-world shopping platforms.
* **Potential Employers:** Recruiters and team leads looking to evaluate my skills in React, Tailwind CSS, TypeScript, and responsive web design.

---

## 🚀 Tech Stack

* **React** (with TypeScript)
* **Tailwind CSS** (for modern and fast styling)
* **React Router Dom** (for page navigation)
* **i18next** (for multi-language support)
